# Node service-v1 extension candidate

Not deployed. Explicit managed service selection queries an already authorized Node-v4 neighbor; no Device STATUS, fallback, forwarding or Account metadata. Old Nodes reject the unknown operation; caller reports unavailable and does not downgrade. This opt-in operation does not change ordinary routing batches or default connection authorization.

MESH_BATCH contains SERVICE_QUERY `{type,version:4,challenge:hex64,expires_at}`. Fresh query nonce and 10-second local timeout, at most eight outstanding browser queries; Python permits four per peer per minute. SERVICE_REPLY carries `{type,version:4,challenge,descriptor,expires_at}` directly to that neighbor. Closing/replacing the channel rejects outstanding queries. After async health work the server rechecks channel authorization and ownership before enqueue.

Descriptor envelope is `{body,signature:hex128}`. Exact body fields: `version:1,issuer,holder,transcript_hash,challenge,issued_at,expires_at,signaling_wss,can_s_turn,can_relay_blob`. Issuer and holder are authenticated Node signing IDs, transcript_hash is the existing secure channel transcript. Signature bytes are Ed25519 over UTF8 `D-MASH|NODE-SERVICE|V4|SERVICE_V1\0` followed by existing secure-session canonical JSON. Strict public/signature encodings use existing discovery guards. Lifetime <=30 seconds; wrong expected Node, holder, nonce, channel transcript, independently provisioned WSS or expired descriptor fails closed.

Backend health uses existing bounded S-TURN health provider; blob permission is backend policy AND healthy S-TURN. An unhealthy signed descriptor revokes prior selection. Browser selector clears prior result before each fresh query, and invalidates on root-session change or expiry. Revocation between queries is bounded by the 30-second descriptor lease, not claimed instantaneous. No new secret or identity is generated.

Managed provision is EMS Node `3e4a0e3f796f8d594e5473249f49460c769bfdd293b4788cdaf78bc314f12b17`, service `wss://stage-api-ems.d-mash.ru/signal/v1`; URL alone confers no health/authentication. Worker verifies signed response; caller-supplied media invitations cannot alter the pin. Real backend service deployment, same-channel Python/Worker acceptance and forced-relay UI remain required before enabling media controls.
